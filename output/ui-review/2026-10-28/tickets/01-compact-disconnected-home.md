## Parent

[#39：修正未连接耳机页布局、传输不可用状态与选择弹窗容器](https://github.com/DOHEX/OpenRose/issues/39)

## What to build

未连接耳机时，两套界面风格都呈现紧凑单列页面：宽屏主内容区内居中、内部左对齐，顶部留白收紧，连接说明、附近设备和扫描操作边界清楚，扫描按钮使用常规宽度。普通说明直接排版，卡片承载完整信息组，Miuix 与 Material 3 保留各自默认组件观感。

本票交付可通过公开应用入口操作和截图独立验证的未连接布局与信息分组。传输不可用时的入口显隐、选择弹窗表面协调分别由同一父规格的其他子票处理。

## Acceptance criteria

- [ ] 传输可用且未连接时，两套界面风格均按连接说明、附近设备、扫描操作组织紧凑单列；宽屏内容区居中、列内左对齐，说明、列表和操作保持一致的内容边界，顶部没有过量留白。
- [ ] 扫描按钮采用文案与库默认内边距决定的常规宽度，保持默认可操作区域；窄屏按可用空间收缩，无横向溢出、重叠或裁切。
- [ ] 普通说明不单独套成细长卡片；卡片承载完整信息组。Miuix 和 Material 3 保持各自表面、字体、形状和主题配色。共用分组修正影响设置或系统页时一并检查这些页面，不扩展为页面职责或全站视觉重设计。
- [ ] 已连接首页的设备信息、降噪快捷操作与功能入口保持可用；沿用既有 680dp 已连接双列断点和 900dp 导航断点。紧凑未连接页允许采用小于既有首页最大宽度的上限，具体尺寸以视觉复核确定。
- [ ] 复用公开 `OpenRoseApp`、合成状态、语义及键盘操作和回调观察验证扫描、停止、候选设备、连接、取消与失败流程；优先复用已有回归。打开页面、改变窗口尺寸或切换界面风格不会自动扫描、连接或写入设置，既有控制会话和页面状态生命周期保持连续。
- [ ] 使用可见几何关系验证宽屏单列、居中、列内左对齐与常规按钮宽度；不绑定私有组件结构、Modifier 顺序或未经确定的像素常量，不新增页面或组件测试入口。
- [ ] 查看两套风格 × 浅色/深色的 360/420dp 窄屏、1280dp 宽屏可扫描未连接首页截图；若共用分组受影响，补查设置与系统页。复核已连接首页 679/680dp、导航 899/900dp 边界。保留可见控件的键盘、辅助功能语义与触控目标。
- [ ] 更新旧“扫描按钮全宽”规则、对应验收预期与布局验证记录；运行受影响的共享 UI 测试及相关既有回归，完成 Android 调试包、本地 Linux 桌面分发构建；外壳受改动时检查本地窗口缩放和顶部区域。
- [ ] 不新增传输实现、自动扫描/连接、型号能力、外观偏好或公开测试专用接口；合成场景、截图及构建的结论限定为对应的界面与交互范围。
