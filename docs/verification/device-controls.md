# 触控、检测、提示音及音频 / 多点控制

日期：2026-10-19（Asia/Shanghai）。范围：i5 [#9](https://github.com/DOHEX/OpenRose/issues/9)、[#11](https://github.com/DOHEX/OpenRose/issues/11)，i7 [#10](https://github.com/DOHEX/OpenRose/issues/10)、[#12](https://github.com/DOHEX/OpenRose/issues/12)。实现基线为 `7354030`。设备暂不可用，用户要求继续实现与离线验证；真实设置与回读验收未完成。

## 控制语义

- 触控请求只包含目标耳、手势和动作的规范化名称，不要求调用者提供原始动作码，也不伪造其他七个槽位的状态。i5 / i7 使用各自的八 / 九种动作码表及左右四种手势。
- 触控绑定是修改耳机手势配置，不是立即播放、调节音量或切换降噪。客户端没有寻机、提示音语言或 OTA 可执行入口。
- 设置后查询完整触控表，但仅用目标槽的有效动作确认该请求。其他槽位的未知动作继续保持未知；目标槽未知或缺失继续等待，有效但不一致返回明确的不一致结果。
- 两型号的触控总开关和检测功能都是协议 `00` 开 / `01` 关。检测功能配置不产生入耳、摘下或入盒事件。
- i5 提示音提供五档，界面 1～5 映射线上 0～4，使用该型号的 `0E03` 查询；不借用 i7 的静音语义。
- i5 音频与多点耦合：AAC/SBC 对应多点开启，LDAC 对应多点关闭。任一入口设置后都重读并确认这两个相关字段，不能分别乐观更新。
- i7 音频配置与多点使用独立指令；不会将 i5 的耦合套到 i7，也不因指令独立就承诺所有实际音频组合都可用。协议配置不是操作系统已经完成的 codec 协商结果。
- 现有型号配置没有为这些触控 / 检测及基础音频功能给出固件门槛，因此不借用 EAP 或增益的版本条件；这不表示所有固件组合已经实测。
- 所有请求继续使用同一权威会话、有界队列和设备回读；风格切换不影响在途命令。超时结束旧链路，断开后清理旧队列，重新连接不重放设置。

协议映射、型号配置及独立向量来源见 [protocols.md](../protocols.md)。

## 验证结果

- 新增 14 项协议测试：独立 TX 字面值覆盖两型号槽位和动作、开关极性、音频 / 多点、i5 五档提示音；验证完整帧、读取计划、非法参数零序号分配、混合序号及合成 / 原始 RX 边界。
- 新增 15 项公开会话测试：覆盖全部八槽、型号动作列表、目标槽投影、未知 / 缺失 / 不一致、双向音频联动或独立、检测与触控总开关、五档提示音、非法参数零发送以及断开 / 切换风格的队列连续性。四组 tracer 场景先观察失败再实现通过。
- JVM 与 Android host JVM 各执行 114 项测试，零失败。以 `--offline` 执行 `check offlineCheck :androidApp:assembleDebug :desktopApp:createDistributable` 全部通过，共 122 项任务。Android host JVM 不是手机设备测试，Linux 桌面构建也不是 Windows 启动验收。
- 独立 `.scratch/device-ui-smoke.sh` 通过，主代理重新运行后结果相同。真实指针操作在设置右耳双击动作的 WRITTEN 阶段切 Miuix → Material 3，仍保留槽位、旧动作、会话和发送量；目标回读确认时其他槽位仍可未知。另验证显式恢复未知目标、未知检测状态的选择、AAC / 多点开启与 LDAC / 多点关闭双向回读、提示音第五档。
- UI 测试共 13 项已有 i5 初始化读取 + 6 次设置 / 回读 = 25 条 TX；i7 受控会话显示九动作、四音频选项、独立多点和本阶段未开放的提示音设置状态。截图、语义树与发送记录位于任务本地 `.scratch/device-ui-smoke/`。只有 i5 初始化 RX 是已有 Linux 捕获；所有设置 RX 及全部 i7 RX 均为合成数据。

## 独立双轴审查

以 `7354030` 为固定基线，两个未参与实现的审查分别检查规范和规格，包含新增文件。

- **Standards**：未发现可执行问题。目标槽投影没有覆盖完整设备状态；界面浏览位置与设备状态分开，按会话隔离且处于风格分支外；所有控制共用同一队列和待处理状态，符合已接受 ADR。
- **Spec**：未发现可执行问题。独立研究确认动作表、左右耳与手势范围、i5 提示音 `0E03` 查询和音频 / 多点联动、i7 独立指令及固件证据；未知状态可恢复，检测配置没有生成实时事件，没有扩大实机或音频协商结论。
