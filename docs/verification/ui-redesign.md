# 分页界面与自适应布局

2026-10-26，按已审阅的 [设计稿](../../output/ui-review/2026-10-26/README.md) 重组共享 Compose 界面。

## 实现

- 手机使用「耳机 / 系统 / 设置」底部导航；宽度达到 900dp 后使用侧栏。耳机首页在内容区域达到 680dp 时采用双列布局。桌面初始窗口为 1180×820dp，仍可缩小至单列布局。
- 首页集中显示真实连接阶段、电量、降噪快捷操作和功能入口。扫描、降噪、均衡器、触控、音频与设备、设备详情、诊断分别呈现；预设与自定义 EQ 使用分段入口。
- 使用灰白背景、白色圆角卡片和蓝色强调，并配套深色外观。Miuix 与 Material 3 的文字、卡片、按钮、开关、滑杆和分隔线分别调用各自组件；耳机插图为原生 Canvas 绘制的中性示意。
- 导航、各页滚动位置、触控槽选择、自定义 EQ 草稿及其视图选择位于风格分支外。会话仍由宿主持有，界面不创建传输，也不因页面或风格切换发送设备设置。Android 接入系统返回处理，桌面支持 Escape 返回详情页上一级。
- 选项保留型号能力和固件条件，待处理时不替换已确认值。未知的设备开关使用明确的「开启 / 关闭」请求入口，不显示为已关闭；提交不产生虚构确认。EQ 模式和曲线仍分别确认，断连后保留已结束会话的操作记录。
- 超级岛、焦点通知、模块连接触发分别设置，系统诊断保留桥接端点及实际状态；调用和提交记录不等于实机验收完成。

## 验证

运行：

```bash
./gradlew --offline :composeApp:jvmTest :core:jvmTest :desktopApp:createDistributable :androidApp:assembleDebug
```

最终结果为成功：核心 176 项、共享界面 8 项测试，均无失败或跳过。Android 调试 APK 和 Linux 桌面发行目录已生成。

新增界面测试通过外部状态和语义操作验证：

- 窄屏添加页与返回、宽屏设置与系统侧栏导航。
- 在自定义 EQ 中创建和修改草稿，经过导航、Miuix→Material 3 及深色切换后保留数值，且没有调用 `onSet`。
- 断连后不再呈现旧设备详情和控制，诊断仍显示旧会话操作记录。
- 两套组件对未知的游戏模式均不宣告开/关状态；显式请求关闭也不会被显示为设备已确认。

已有四项降噪 UI 测试继续验证档位随设备确认模式变化、未知模式隐藏档位、自定义能力选项及待确认状态。
