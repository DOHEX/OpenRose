# i5 / i7 降噪控制实现与离线验证

日期：2026-10-19（Asia/Shanghai）。范围：[i5 降噪模式、档位与轮换 #5](https://github.com/DOHEX/OpenRose/issues/5) 和 [i7 降噪模式、档位与轮换 #6](https://github.com/DOHEX/OpenRose/issues/6)。真实设备暂不可用，用户明确要求继续实现与离线验证；实机验收保持未完成。

## 控制与能力

- i5 提供普通、通透、抗风和降噪四种模式；i7 另提供有型号配置证据的自动与动态模式。i5 自动模式、i7 深度模式没有可执行入口。
- 两型号提供档位 1 / 3 / 5，但线上编码分别映射，不能共用原始值。轮换发送顺序也分别处理。
- 型号能力同时声明允许模式、档位、轮换选项和最少选择数量。恢复的配置与发送器未对轮换规定最少选择数量，因此客户端允许显式清空；设备是否接受空列表仍需实测。
- i7 型号配置中未发现自动 / 动态降噪的固件门槛，因此不凭空增加版本限制；这不表示所有固件组合已实测。其他受限功能未在此阶段开放。
- 设置、回读和初始化共享同一会话与协议实例；i7 序号继续递增，不为设置另建连接或重置序号。设置前校验能力、类型、范围与完整报文容量。

## 队列与确认语义

- 提交、底层写入完成和设备确认是不同阶段。设备字段只由实际通知解析更新；请求值独立保存在操作记录，不直接修改已确认状态。
- 同一会话拥有有界串行队列，设置后发送独立读取命令，以新的字段结果确认。旧缓存、设置 opcode 的机械变换及未知字段不能成为成功确认。
- 新回读与请求一致为确认；已知回读不同为“不一致”，不声称收到了协议拒绝码。未知或未提供字段等待截止时间。
- 超时意味着无法可靠关联迟到回复，客户端保守结束旧链路：当前请求保留超时结果，后续队列结束，不重放设置。重新连接会重新读取，不重发原请求。
- 界面风格切换只改变组件，控制和操作记录留在平台宿主持有的会话；断开后仍保留有界的操作结果。

## 验证结果

- 新增 8 项协议测试：覆盖两型号模式、档位、轮换、读回计划、拒绝边界、输入快照与序号连续 / 回绕 / 重置，使用独立 TX 字面值及已恢复参数映射。
- 公开会话设置测试覆盖提交 / 写入 / 确认阶段、无乐观更新、缓存不可确认、未知回读超时、回读不同、非法参数零发送、并发 FIFO、调用者取消、切换风格、断开、迟到回复、重新连接不重放及帧容量 / 写入节奏。
- 独立 `.scratch/anc-ui-smoke.sh` 在离屏 Compose 中实际点击真实 `OpenRoseApp`。传输边界重放 i5 13 项原有 Linux RX，设置回复明确为合成数据；没有给产品添加演示开关或假设备。
- UI 测试验证：在 WRITTEN 阶段切换 Miuix → Material 3，仍保留旧的已确认模式，控件禁用、会话标识不变；合成读回后才显示新模式与确认结果；再次设置超时，没有自动重放。总发送量为 13 条初始化 + 2 条设置 + 2 条回读 = 17。
- 受控界面截图、语义树、完整 TX 与结果保存在任务本地 `.scratch/anc-ui-smoke/`。此结果是共享 UI / 会话集成测试，不是 Bluetooth、Android 手机或耳机实测。
- 修复审查问题后，JVM 与 Android host JVM 各执行 65 项测试，均为零失败；其中公开会话设置场景为 22 项。Android host JVM 不是手机设备测试。
- `check offlineCheck :androidApp:assembleDebug :desktopApp:createDistributable` 全部通过，共 122 项任务；额外的 `--offline offlineCheck` 通过。检查涵盖 Android lint、两平台共享编译及 Linux 桌面分发构建，不等于 Windows 启动或真实传输验证。

## 独立双轴审查

审查范围：`1f9ed60` 起的降噪控制实现（首轮提交 `3d68a98`）。两个独立审查分别检查仓库规范与 #1、#5、#6 的规格。

- **Standards**：未发现可执行的规范问题。平台宿主持有会话、协议实例与队列，两套风格共享状态和操作；符合 ADR 0001 / 0002。
- **Spec**：发现并修复一项 P2：轮换字段外层是 Known，但内部某个开关可能未知，此时不能立即报告设备回读不同。修复要求全部轮换开关已知后再比较；新增两型号共 6 例回归，覆盖等待后完整确认、持续未知超时、完整已知但不同。红阶段 4 例暴露缺陷、2 例验证原有不一致行为；绿阶段 22 项设置场景全部通过。原审查者定向复核后确认问题解决，无新增发现。选项、编码、固件边界和未实测声明符合本阶段规格。
