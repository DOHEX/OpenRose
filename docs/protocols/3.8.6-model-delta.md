# RoseLink 3.8.6 耳机注册与版本差异

Android 客户端 `cn.ikaile.ruoshui.client` 3.8.6（5495）注册 **48 个蓝牙耳机配置**，包括 39 个 `tws`、9 个 `head`。同名硬件分支按配置计数。本文记载 APK 静态行为，附[完整注册清单](supported-devices-3.8.6.json)。历史协议资料继续使用 [3.8.0 清单](00-supported-models-and-capabilities.md)。

## RS Common V2 的实际握手查询

3.8.6 的全部 31 个 V2 蓝牙耳机配置使用按型号生成的 `FA` 查询。应用的普通蓝牙握手分派到各型号 `sendInitCommands`，继而调用 `RCommander.getInfo`。构建 Commander 时，配置的 `queryInfoByFeatures` 根据协议族启用覆盖列表。有覆盖列表时，`getInfo` 发送该列表，跳过 Sender 内置的 29 项后备查询。本次 6 款新增耳机中，4 款 V2 使用此逻辑，RS Common 的 Cambrian S、OpenLink 仍走普通 Sender。F8、ZT、RS Common 的判断结果均为 false。V2 调试配置、AURAMIC 麦克风和 USB Audio 配置另有直接返回 false 的实现。普通握手分派（`rose_reverse/analysis/3.8.6/blutter/asm/roselink/lib/global_controller.dart:4231`）、协议族门槛（`rose_reverse/analysis/3.8.6/blutter/asm/roselink/rose_bluetooth/config/base_device_config.dart:3336`）、Commander 构造（`rose_reverse/analysis/3.8.6/blutter/asm/roselink/rose_bluetooth/config/base_device_config.dart:1048`）、覆盖与后备分支（`rose_reverse/analysis/3.8.6/blutter/asm/roselink_bluetooth/commander/r_commander.dart:3539`）

## 再生成

在 rose_reverse 根目录使用同一份 APK 和 Blutter 提交 `528acbe83ba35a3a53fb97b231cb5f968c7068d1`。以下命令复用项目已有的 Dart 3.11.4 分派表读取器。大型文件在本机生成，3.8.0 的反汇编和索引可继续单独使用。

```sh
unzip -o RoseLink_3.8.6.apk 'lib/arm64-v8a/libapp.so' 'lib/arm64-v8a/libflutter.so' -d analysis/3.8.6/extracted
python3 ../blutter/blutter.py analysis/3.8.6/extracted/lib/arm64-v8a analysis/3.8.6/blutter
python3 analysis/i7_dispatch/build.py
analysis/i7_dispatch/helper analysis/3.8.6/extracted/lib/arm64-v8a/libapp.so analysis/3.8.6/table.tsv
python3 -I analysis/3.8.6/build_registry.py
```
