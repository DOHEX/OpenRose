# 型号适配证据账本

本账本覆盖已接入的型号配置：既有四款 RS Common V2 扩展，以及新增 i3、HeadFeel、六个 F8 配置、九个 RS Common 配置。证据来自型号文档、协议族及结构化清单；新增型号均无本项目实机验证，合成夹具不是设备抓包。A：共用编解码与配置；B：族内差异；C：新能力类型；D：新协议族；不实现：证据不足、无法确认或范围外。

## ZT 型号逐行证据账本

分类 A=族内相同，B=型号差异，C=新能力，未实现=没有足够证据或当前控制模型不支持。除明确写“未知”外，下面型号文档证据均为静态、非实机；来源分别为 `docs/protocols/models/earfree-i3-protocol.md`、`headfeel-protocol.md` 对应章节，族默认值为 `docs/protocols/families/zt.md`「默认传输」，清单为 `00-supported-models-and-capabilities.md`「F8、ZT、RS Common」。无 i3 或 HeadFeel 实机验证。

### EarFree-i3

- 识别表零售 TWS：`f10203`、`010203`、EarFree-i3，A；清单的 ZT、左/右/盒和 BLE 均与之相符，A。
- 传输表：BLE 服务 `011bf5da-0000-1000-8000-00805f9b34fb`、写 `00007777-0000-1000-8000-00805f9b34fb`、通知 `00008888-0000-1000-8000-00805f9b34fb`，A；SPP 否及 UUID 未配置 A；广播经典地址未证实，未实现（未知）；100ms 族默认 A；OTA 服务与特征 `65786365-6c70-6f69-6e74-2e636f6d0000/0001` 静态，OTA 范围外未实现。
- 初始化表每行：`0101`、`0602`、`0201`、`0603`、`0801`、`0401`、`0a01` A；`0b01` B（回包极性未知）。按表顺序发送 8 条。
- 电量：`0101` 左 byte11、右 byte12、左右充电 byte13/14、盒 byte15，FF 不提供，A。
- 设置命令表逐行：电量读取 A；降噪 `0682` ANC `010000`、普通 `000001`、通透 `000100` B；EQ POP/HIFI/ROCK `00/01/02` A；游戏 `0683` 开00关01 A；多点 `0881` 开00关01 与音频耦合 A；音频 `0881` AAC/SBC00、LDAC01 A；触摸 `0481` 左右×单双三及动作 00/01/02/03/05/06 B；触摸开关 `0a81` 开00关01 A；隐藏搜索 `0b81` 开01关00，C 未实现：回包极性和 UI 语义未知，现有设置队列无法确认结果；OTA 未实现（范围外）；面板容器和更多入口是结构，未实现为协议设置。

- 清单能力逐列：ANC/普通/通透、POP/HIFI/ROCK、单/双/三、游戏、AAC/SBC+LDAC、多设备均如上；佩戴与寻机无入口；隐藏搜索如上未实现；OTA WQ 范围外，更多设置仅结构。OTA 节的语言固件选择和元数据未知，不实现。

### HeadFeel

- 识别表零售头戴：`525300020002`、HeadFeel/HeadFree，B；清单 ZT、单体电量与 BLE/SPP 同证。
- 传输表：族默认 BLE 服务、写和通知 UUID 同上 A；SPP 是、UUID `0cf12d31-fac3-4553-bd80-d6832e7b3931` B；广播经典地址未证实未实现（未知），写间隔 100ms 族默认 A；BES OTA 通道范围外未实现。

- 电量：`0103` byte9 单体 charge，左/右不发布 B；不将 `0101` 作为单体电量。
- 设置命令表逐行：单体电量 B；降噪四字节 ANC/普通/抗风/通透 A；ANC 和通透 UI 1/3/5 写 01/02/03，回读 00/01/02 B；EQ POP/HIFI/ROCK A；自定义预设 `0281 03` 版本≥130 B；自定义曲线 `0282` 10 符号绝对值字节，界面标签 20/100/300/500/1k/2k/3k/5k/8k/15k Hz、−6..+6、步长 1，版本≥130，帧 20 字节，读回 `0201` 与 `0202`，B；频点是界面标签，不是实测滤波器中心；增益 `0283` UI0/1/2→01/02/03、固件≥130 B；游戏 `0683` A；独立多点 `0882` 开01关00、读0802 B；音频 `0881` 00/01/02/03 对应 AAC/SBC、LDAC、LHDC、LDAC+LHDC B；寻机发 `0e82` 停 `0e02`，C 未实现：收到事件被原 App 丢弃，现有队列无可确认状态；触摸 `0481` 电源单/双/三、ANC键双/三、8动作 B；触摸开关 A；提示音 `0e03` 直接1..5 B；降噪轮换 `0685` A；OTA BES 未实现（范围外）；面板容器和更多入口是结构，不实现为协议设置。

### 族风险与合成样本

两型号无实机证据；共用 BLE 订阅后再初始化、100ms 写间隔，TX 和校验仅适用 TX，RX 无已证明帧校验；HeadFeel SPP 地址及实际连接未知；i3 三字节降噪写入与回包尾部未闭合；HeadFeel 等级读写线值偏一档；HeadFeel 自定义 EQ 的 `0282` 帧为 20 字节（早先记录的 22 字节有误），刚好等于默认 BLE 写入容量；任何不可识别枚举保留 Unknown。`ZtModelProtocolTest` 接收报文均是合成示例而非实机抓包。

### 初始化（各型号“初始化”；族“固定命令”）
