# 未连接首页布局：#39 / #40

## 规则

未连接首页使用宽屏居中的紧凑单列和各组件库的紧凑顶栏；列内按连接说明、连接状态、扫描操作与附近耳机组织。扫描、停止和重试操作位于候选列表之前；只展开已识别的耳机，其他蓝牙设备由用户按需展开，避免无关设备挤走操作入口。缺少广播名称的已识别耳机使用型号名称。当前内容上限为 600dp，窄屏保留页面边距并随窗口收缩。扫描按钮按文字和组件默认尺寸排版，此规则替换旧版默认样式 6.2 的“扫描按钮全宽”。

附近设备为空时，说明直接使用页面表面；有候选设备时，Miuix 卡片承载设备信息及连接操作，Material 3 保留默认列表与分隔线。设置页的保存提示直接排版，系统页就绪状态说明与其状态保持同组并有适当内边距。组件字体、形状和配色沿用各库默认值。已连接首页继续使用 1120dp 内容上限及 680dp 双列断点，其他页面使用 800dp 上限，导航保留 900dp 断点。

真机体验后的交互修正：耳机设置的操作反馈覆盖在内容区底部，不参与页面滚动布局；成功提示只针对当前页面观察到的待确认操作，在确认后短暂显示，离开页面不重播。首页快捷降噪区覆盖型号能力允许的模式，按可用宽度分行，选中态仍以设备回报为准。Miuix 已知选择值使用下拉组件自带的选中展示，不再通过副标题重复显示。

宽屏中内容位于主内容区中央，说明、附近设备及常规宽度扫描按钮从左向右阅读；紧凑顶栏后即可见内容。窄屏中的说明与操作未见裁切、覆盖或横向溢出。Miuix 空列表说明不再出现细长卡片，候选设备和连接操作位于完整卡片内；Material 3 的列表与分隔线保持自身默认观感。设置保存提示位于页面表面；系统就绪说明与状态行左边缘对齐，并留有卡片内边距。
