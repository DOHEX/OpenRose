# 未连接首页布局：#39 / #40

## 规则

未连接首页使用宽屏居中的紧凑单列和各组件库的紧凑顶栏；列内按连接说明、附近设备、扫描操作与连接状态组织。当前内容上限为 600dp，窄屏保留页面边距并随窗口收缩。扫描按钮按文字和组件默认尺寸排版，此规则替换旧版默认样式 6.2 的“扫描按钮全宽”。

附近设备为空时，说明直接使用页面表面；有候选设备时，Miuix 卡片承载设备信息及连接操作，Material 3 保留默认列表与分隔线。设置页的保存提示直接排版，系统页就绪状态说明与其状态保持同组并有适当内边距。组件字体、形状和配色沿用各库默认值。已连接首页继续使用 1120dp 内容上限及 680dp 双列断点，其他页面使用 800dp 上限，导航保留 900dp 断点。

## 本票视觉复核（2026-10-28）

离屏 Compose 场景经公开 `OpenRoseApp` 注入可扫描、尚未连接的合成状态，密度为 1，查看了 Miuix 和 Material 3 两种风格、浅色和深色、360/420/1280dp 的 12 张首页截图；截图与生成用测试源保存在本机 `/tmp/openrose-spec39/evidence/layout/`。还查看了 1280dp 的两种风格候选设备页、Miuix 浅色设置页和深色系统页，以及 Material 3 深色设置页和浅色系统页。

宽屏中内容位于主内容区中央，说明、附近设备及常规宽度扫描按钮从左向右阅读；紧凑顶栏后即可见内容。窄屏中的说明与操作未见裁切、覆盖或横向溢出。Miuix 空列表说明不再出现细长卡片，候选设备和连接操作位于完整卡片内；Material 3 的列表与分隔线保持自身默认观感。设置保存提示位于页面表面；系统就绪说明与状态行左边缘对齐，并留有卡片内边距。

这些截图覆盖本票所改的合成可扫描状态与代表性分组；传输不可用、对话框、已连接边界及原生窗口缩放的集成截图另行复核。离屏结果不证明真实耳机连接或系统集成功能。
