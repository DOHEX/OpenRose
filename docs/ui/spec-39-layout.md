# 未连接首页布局：#39 / #40

## 规则

未连接首页使用宽屏居中的紧凑单列和各组件库的紧凑顶栏；列内按连接说明、连接状态、扫描操作与附近耳机组织。扫描、停止和重试操作位于候选列表之前；只展开已识别的耳机，其他蓝牙设备由用户按需展开，避免无关设备挤走操作入口。缺少广播名称的已识别耳机使用型号名称。当前内容上限为 600dp，窄屏保留页面边距并随窗口收缩。扫描按钮按文字和组件默认尺寸排版，此规则替换旧版默认样式 6.2 的“扫描按钮全宽”。

附近设备为空时，说明直接使用页面表面；有候选设备时，Miuix 卡片承载设备信息及连接操作，Material 3 保留默认列表与分隔线。设置页的保存提示直接排版，系统页就绪状态说明与其状态保持同组并有适当内边距。组件字体、形状和配色沿用各库默认值。已连接首页继续使用 1120dp 内容上限及 680dp 双列断点，其他页面使用 800dp 上限，导航保留 900dp 断点。

真机体验后的交互修正：耳机设置的操作反馈覆盖在内容区底部，不参与页面滚动布局；成功提示只针对当前页面观察到的待确认操作，在确认后短暂显示，离开页面不重播。Miuix 单选设置的已知选择值使用下拉组件自带的选中展示，不再通过副标题重复显示。

## 已连接首页降噪与游戏模式（2026-10-30）

- 首页按型号能力生成上图标、下文字的模式选项。i5 的标准、降噪、通透、抗风噪保持单行四项；i7 额外提供自动、动态降噪，按两行三项展示。选中项使用强调色图标和浅色圆形底，整项可点击。
- 降噪档位与通透档位继续放在首页，只在相应的设备已确认模式下显示；其他模式隐藏两组档位。模式请求不提前改变选中态或档位区域。
- “更多降噪设置”及其重复二级页移除，替换为“降噪轮换”多选入口。该低频入口位于首页功能列表靠下，在均衡器、触控操作、音频与设备之后、设备详情之前，不占用降噪模式卡片。Miuix 使用 `OverlayDropdownPreference` 并保持展开，Material 3 使用多选对话框。入口摘要列出所有已确认参与项，关闭 Miuix 默认的首项尾部值，避免把多选显示成单选。
- 轮换参与项单独由型号能力决定；当前两款型号均为四种常规模式，不包含 i7 的自动、动态降噪。每次修改立即提交，设备确认后才更新选中态，等待期间禁用操作；允许全部不选，摘要显示“未选择轮换模式”。轮换配置不立即改变当前降噪模式。
- 返回或点击外部关闭选择浮层；关闭不撤销已提交设置。风格切换保持选择浮层和已确认设备状态，不重发命令。轮换状态尚未完整读取时禁用配置。
- 支持游戏模式时，在降噪卡片下方、功能列表上方显示独立开关；均衡器页移除同名开关。入口和选项继续依据能力展示，游戏模式能力本身不产生均衡器入口。
