# Spec: 添加耳机页重设计

## 决策状态

用户已确认两轮设计选择：Q1–Q3 的页面范围、视觉方向与双风格支持，以及 Q4–Q8 的设备卡片、搜索时长、权限引导、连接状态与辅助入口。

用户已在 Q9 确认完整方案并授权实施；以下交互与状态规则作为实现及验收依据。

## Problem Statement

当前添加耳机页以提示文字、扫描按钮和普通设备列表为主，缺少明确的搜索视觉焦点。设备摘要直接展示协议配置和 dBm，权限、连接阶段、错误与搜索结果分别堆叠，削弱了选择耳机这一主要操作。

当前代码还存在成功判定与既有决策不一致的问题：`ControlSession.connectInternal` 在 `CONNECTING` 阶段即创建设备状态，`ControlState.activeDevice()` 包含匹配的连接中设备，而 `OpenRoseApp` 用该状态是否存在决定退出添加页，因此连接刚开始就可能返回主页。[ADR 0008](../adr/0008-unconnected-device-dashboard-and-add-device-flow.md) 约定的是控制连接就绪后返回。

## Solution

重设计现有 `Route.AddDevice` 独立全屏页，沿用主页入口及返回方式，隐藏底部导航。Miuix 与 Material 3 使用相同的信息结构和状态规则，各自使用对应风格的组件、颜色、文字与形状。

信息结构由上至下为：

1. 返回入口与“添加耳机”标题。
2. 耳机插画、搜索动效和“打开耳机并靠近设备”的指引；缺少权限或蓝牙关闭时，该区域改为当前前置条件的引导。
3. 搜索状态及“停止搜索”或“重新搜索”操作。
4. 附近受支持耳机的设备卡片。
5. 低优先级“找不到耳机？”入口，展开排查指引、系统蓝牙设置、其他蓝牙设备和诊断入口。

复用现有耳机插画与应用主题、页面容器，不添加新的根主题或重复的页面外壳。窄屏纵向排列，宽屏限制内容宽度，设备列表可滚动；小屏与放大字体下仍可访问设备和主要操作。动效只表示真实搜索或连接状态。

## 已确认的交互

### 设备卡片

- 主列表只显示已识别且受支持的耳机。
- 每张卡片显示耳机图、设备名称和明确的“连接”按钮。
- 按本轮首次发现顺序排列；同一设备的后续广播更新原卡片，不重复插入，也不按信号变化重排。
- 同名设备补充设备地址末几位作为区分信息。
- dBm、协议配置与原始诊断信息不作为卡片主摘要；保留在辅助排查路径中。
- 连接期间，所选卡片展示进度，其他卡片不可发起连接，避免并发提交。

### 搜索

- 进入页面且前置条件满足时自动搜索；权限未满足或蓝牙关闭期间不计入搜索时长。
- 每轮实际搜索最多持续 20 秒。到期停止搜索及搜索动效，不把正常到期描述为错误。
- 搜索期间可手动“停止搜索”；停止或到期后保留本轮已发现设备，仍可连接。
- 无结果时显示未找到耳机的状态，并提供开启耳机、进入配对模式和靠近设备的指引。
- “重新搜索”启动新一轮搜索，重置本轮计时和结果；仍按首次发现顺序展示。
- 后续广播、界面重绘及界面风格切换不重置本轮计时。
- 离开添加页时停止该页发起的搜索。

### 权限与蓝牙前置条件

- 缺少权限时，以权限说明及“授予蓝牙权限”为主要内容，不同时展示空结果或不可用的搜索按钮。
- 系统蓝牙关闭时，以蓝牙关闭说明及“打开蓝牙设置”为主要内容。
- 权限需从系统设置恢复时，使用平台实际支持的设置入口，不反复触发无效的权限申请。
- 前置条件恢复后自动开始新一轮搜索；没有可用蓝牙传输的平台呈现真实原因。
- 前置条件不满足时停止搜索，不继续播放搜索动效。

### 连接、取消与失败

- 点击“连接”后停止搜索，保留本轮列表和所选设备，在本页显示连接进度。
- 页面用易懂文案呈现现有连接阶段，不显示虚构百分比。
- 连接期间可“取消连接”；取消后留在本页，恢复可操作的设备卡片和“重新搜索”入口。
- 返回按钮、系统返回和完成的返回手势均结束本页发起的未完成连接并退出；取消的返回手势不触发退出清理。
- 连接失败时留在所选设备卡片内说明失败并提供“重试”，辅助路径保留系统蓝牙设置和诊断详情。
- 只有本次添加所选设备的控制会话达到 `ConnectionPhase.READY` 时才返回“我的耳机”主页；不能用设备状态存在、连接开始或已有其他连接作为成功判据。
- 成功退出页面时保留已就绪的控制连接；页面清理不得将其断开。退出清理也不得取消不属于本次添加的其他会话。
- 界面操作使用“连接”，添加成功遵循[词汇表](../../GLOSSARY.md)定义，不承诺系统音频配对或播放连接已完成。

### 辅助排查

- “找不到耳机？”作为页面内可展开的辅助区域，不遮挡主流程。
- 展示开启耳机、进入配对模式、靠近设备等指引，并提供系统蓝牙设置入口。
- 未识别设备放入“其他蓝牙设备”，标明暂不支持，不能发起控制连接。
- 保留诊断详情入口；查看诊断导致离开添加页时遵循停扫与未完成连接清理规则。

## 状态与主要操作

| 状态 | 主要呈现 | 可用操作 | 下一步 |
| --- | --- | --- | --- |
| 缺少权限 | 权限说明 | 授予权限或进入系统设置、返回 | 条件恢复后自动搜索 |
| 蓝牙关闭 | 蓝牙关闭说明 | 打开蓝牙设置、返回 | 条件恢复后自动搜索 |
| 传输不可用 | 实际不可用原因 | 返回；平台支持的辅助入口 | 不启动搜索 |
| 搜索中，无结果 | 耳机插画、搜索动效与指引 | 停止搜索、辅助排查、返回 | 发现设备或搜索结束 |
| 搜索中，有结果 | 搜索状态与设备卡片 | 连接、停止搜索、返回 | 连接或搜索结束 |
| 搜索结束或手动停止 | 本轮结果；无结果时呈现指引 | 连接已有结果、重新搜索、辅助排查、返回 | 新搜索或连接 |
| 搜索失败 | 失败说明与可保留的已发现设备 | 重新搜索、连接仍可用设备、辅助排查、返回 | 新搜索或连接 |
| 连接中 | 所选耳机与真实阶段 | 取消连接、返回 | 就绪、失败或取消 |
| 连接失败 | 所选卡片内的失败说明 | 重试、选择其他设备、重新搜索、辅助排查、返回 | 新连接或搜索 |
| 连接取消 | 保留设备列表 | 连接、重新搜索、返回 | 新连接或搜索 |
| 本次连接就绪 | 转入主页控制看板 | 主页已有操作 | 保持控制连接 |

## Implementation Boundaries

- 页面仍由现有导航和应用容器承载；不改变“我的耳机”主页、添加入口、协议支持范围或系统音频配对管理。
- 搜索时限属于添加页的一轮搜索，不把其他搜索使用方改为统一 20 秒超时。
- 共享控制会话继续拥有实际扫描和连接；页面管理本次操作的意图与生命周期，不创建第二个会话所有者。
- 添加页通过可取消的 `ControlSession.connectForAddDevice` 等待本次操作的结果；取消仅清理该调用新建且尚未就绪的会话。复用其他入口已创建的会话时，取消添加页的等待不会断开共享连接。
- 成功判定与取消清理关联本次所选设备及会话，避免旧会话、迟到回调或其他设备的状态变化触发误返回或误取消。
- 两套界面风格消费相同状态与操作；风格切换不重复发起搜索、连接或成功导航。

## 验收条件

1. 既有入口进入添加页后，满足条件即自动搜索，底部导航隐藏；两套风格均展示相同功能。
2. 无权限、权限恢复、蓝牙关闭、蓝牙恢复及传输不可用状态均有真实呈现，搜索与主要操作符合状态表。
3. 每轮搜索在 20 秒内有结果、无结果、手动停止和扫描失败的路径均能正确收敛；正常到期保留结果，重新搜索开启独立新轮次。
4. 重复广播不产生重复设备卡片或改变首次发现顺序；同名设备可区分。
5. 点击连接后页面不提前返回；连接中可取消，失败可原位重试，其他设备不会并发连接。
6. 返回按钮、系统返回与完成的返回手势停止搜索并取消本次未完成连接；成功导航保留已就绪会话。
7. 只有本次所选会话就绪才返回主页；连接中设备状态、已有连接和迟到回调均不误触发成功。
8. 辅助区域可访问未识别设备、系统设置和诊断；未识别设备不能连接。
9. Miuix 与 Material 3 在浅色、深色、小屏、宽屏和放大字体下，主要操作可达，文本与状态不只靠颜色区分。

## 验证结果

- 完整回归通过：`core:jvmTest` 的 190 项测试及 `composeApp:jvmTest` 的 74 项测试均无失败或跳过。
- Android Debug 构建与 Desktop JVM 编译通过。验证命令：`./gradlew :core:jvmTest :composeApp:jvmTest :androidApp:assembleDebug :desktopApp:compileKotlinJvm`。
- 添加页回归覆盖 20 秒到期与重新搜索、风格切换和广播更新不重置计时、权限与蓝牙恢复、取消连接、失败重试、就绪返回及其他设备／较新会话的隔离。连接中提前返回的回归用例在修复前失败、修复后通过。
- 实际离屏渲染检查了两套风格的搜索、连接中、失败和成功返回，以及深色、360dp 大字体、1200dp 宽屏和同名设备卡片。宽屏添加页隐藏侧栏；离场页面读取实时路由，避免旧返回控件残留在无障碍树中。
- 已安装到连接的小米 14，实际检查 Miuix 与 Material 3 添加页、自动搜索、搜索结束空态、排查指引、系统返回及边缘返回手势。短距离手势取消后仍留在添加页搜索，完成手势返回主页；验证后恢复原 Miuix 偏好并返回主页。
- 本轮实机未发现可连接的受支持耳机；连接成功、失败重试与会话取消由可控传输及 UI 回归场景验证，未将其记为真实耳机连接实测。
- 临时视觉冒烟源码和调试输出已移除，设备上的临时截图与界面转储已清理。
