# 设置写入分组、可写门控与均衡器写入顺序

[ADR 0016](0016-equalizer-entry-by-capability.md) 规定所有设置只显示设备已确认的值，写入期间只锁定同一写入组的设置。本 ADR 记录界面何时接受新的写入、写入组如何划分，以及均衡器页连续选择时如何排队。

## 决策

### 写入分组与可写门控

- **可写条件**：`OperationFeedback.kt` 的 `ControlState.canWrite` 判断一项设置能否接受新的写入：它所需的会话可用，且同一写入组内没有仍在进行的写入（阶段为 `SUBMITTED`、`PARTIALLY_WRITTEN` 或 `WRITTEN`）。
- **同组互相等待**：同组的设置会改变彼此的含义（档位属于某个降噪模式，触控绑定属于它的开关），所以互相等待。`writeGroup` 的划分：
  - 降噪档位、通透档位、降噪轮换归入降噪模式；
  - 自定义曲线归入均衡器模式；
  - 触控绑定归入触控开关，敲击绑定归入敲击开关；
  - 空间音频模式与内容归入空间音频开关；
  - 独立麦克风模式归入独立麦克风开关；
  - 其余设置各自成组。
- **无关设置保持可写**：不同组的设置可以同时提交，在核心的控制队列中按顺序排队。
- **降噪模式更早可写**：降噪模式只需降噪模式会话可用（`ControlState.canControlNoiseMode`，对应 `noiseModeSession`），早于会话就绪；降噪档位与降噪轮换仍要等就绪会话（`isReady`）。`canChooseNoiseMode` 还要求型号能力把降噪模式列为可写。

### 均衡器写入顺序

- **写入曲线即选中自定义模式**：两个协议族都先发模式，再发增益。RS v2（`RsCommonV2Codec.customEqualizer`）先写 `0x2a 4`，再写 `0x3e` 与曲线；ZT（`ZtCodec.customEqualizer`）先用 `0281` 选中预设表中 `custom` 的槽位，再用 `0282` 写曲线。两者都回读模式，并另行回读曲线。
- **一次只写一个**：`EqualizerEditor` 把均衡器页的选择逐个发往一个设备会话。写入进行中，新的选择互相覆盖，只在当前写入结束后发送最后一个。
- **显示规则**：队列清空前，页面把最新的选择标为正在写入，并显示它的曲线（`displayedCurve`），选中的模式仍是设备已确认的模式（`pendingMode` 只用于标出进度）。队列清空后显示设备确认的值，因此写入失败或未生效时自然回到设备自身的状态，不需要单独的回滚路径。
- **跨界面风格保留**：`EqualizerEditor` 与其他应用级界面状态一起保存在 `OpenRoseApp`，切换界面风格不会丢掉仍在写入的选择。会话变化时（`bind`）取消写入并清空队列。

## 后果

新增设置时，若它的含义依赖另一项设置，要在 `writeGroup` 中归入那一项，否则二者可能同时写入。降噪模式能在会话就绪前操作，依赖降噪模式的界面（托盘面板等）不能用 `isReady` 判断它是否可用。均衡器的连续拖动只会产生“当前写入 + 最后一次选择”两次写入，中间的选择不会发到耳机。
