# 均衡器入口按型号能力分流

均衡器入口来回改过两次。Spec #55 把二级页 `Route.Equalizer` 换成耳机主页内联的均衡器下拉偏好行；为了编辑自定义曲线，a31fd07 又恢复了二级页，所有型号都从主页箭头进入，在页内选择预设、编辑曲线。这两种做法各自只适合一部分型号：

- 带均衡器的 16 个型号中有 13 个只有预设。对它们而言，二级页只有 2–4 个选项，为一次单选多走一层页面。
- 曲线编辑需要整页：10 个频段的拖动、刻度与数值放不进主页的一行。
- 预设的真实曲线在固件 DSP 里，OpenRose 读不到。预设模式下显示自定义曲线，会被误读为该预设的曲线。

## 决策

- **主页入口按当前能力分流**：主页“功能”分组仍只有一个“均衡器”入口。有可写自定义曲线的型号（i7、HeadFeel 固件 ≥130、OpenFeel MK2）用箭头行进入均衡器页；只有预设的型号用选择行，在主页直接选择预设并写入，不经过均衡器页，进度与失败由主页的设置反馈呈现。两种入口都只显示设备已确认的模式。能力随固件变化时入口形态随之重新渲染：HeadFeel 读到固件 ≥130 之前按只有预设处理。
- **均衡器页按模式呈现曲线**：“模式”是纵向单选列表，预设在前，“自定义”在最后；没有预设的型号不显示它。“自定义曲线”卡片只在显示的模式为自定义时出现，没有预设的型号始终出现。从预设切到“自定义”即写入当前曲线（已读到的耳机曲线，未读到时为平直曲线）。曲线左侧标出型号的增益上下限与 0，不标单位，因为增益单位没有证据。
- **页面不随能力变化离开**：停在均衡器页时能力变为只有预设（换主耳机、重连到只有预设的型号），页面按当前能力渲染、曲线卡片消失，不自动返回；断开时沿用“耳机已断开”占位。

## 考虑过的方案

- **所有型号都从主页下拉选择（Spec #55）**：自定义曲线无处编辑。
- **所有型号都进入均衡器页（a31fd07）**：13 个只有预设的型号为 2–4 个选项多走一层页面。
- **把预设选择与自定义曲线拆成两个入口**：同一个模式被拆到两处，用户要先弄清两者的关系；词汇表已将其列为应避免的做法。
- **预设模式下也显示曲线，并淡化处理**：仍会被误读为预设的曲线，见上文。

## 后果

主页的“均衡器”行有两种形态，测试需按型号能力分别覆盖。一个型号若将来开放可写曲线，只要其能力声明 `CUSTOM_EQ` 可写并给出曲线能力，入口就自动改为进入均衡器页，无需改界面代码。
