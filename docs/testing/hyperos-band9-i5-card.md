# 小米手环 9 NFC 融合设备中心与 Linux 所连 i5

2026-11-21，小米手环 9 NFC 真机原型在设备发现阶段失败。Linux 正通过 EarFree i5 播放时，用户从手环打开融合设备中心，实看腕屏后报告「列表里找不到 i5」。因此无法打开耳机卡片，也没有从腕上发出降噪操作。[工单 #117](https://github.com/DOHEX/OpenRose/issues/117)

| 本次环境 | 记录 |
| --- | --- |
| 手环 | 小米手环 9 NFC，保持连接小米 14。用户在手环设置中确认固件版本为 `3.1.32`。 |
| 手机 | 小米 14（23127PN0CC），Android 17，HyperOS OS4.0.0.27.XNCCNXM，系统互联服务 18.2.2.0.2609141543，运动健康 3.59.1。OpenRose 显示版本为 `0.0.0-dev+f5652f5`，含局域网路由修复。 |
| 电脑 | CachyOS，内核 7.3.3，BlueZ 5.88，PipeWire，桌面 OpenRose 基于 `eb6a4a3`。 |
| 连接 | 手机选择模块控制，已通过六位码与电脑完成流转配对。i5 关闭多点，由电脑独占，手机与 i5 的音频及控制蓝牙链路均已断开。 |

腕端检查期间，Linux 的 i5 输出为 `RUNNING`。用户在本次验收中听到了电脑经耳机播放的测试音。持有端读到左耳 86%、右耳 88%，盒电量未知，已确认模式为通透。手环列表缺少 i5，未能执行从其他模式切到通透的步骤，也没有对应腕端请求的耳机回包。

本次腕屏观察由操作手环的用户提供。[同场手机与电脑流转配对记录](i5-circulation-pairing.md)
