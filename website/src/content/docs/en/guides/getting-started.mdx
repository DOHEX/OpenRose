## Requirements

- Android 8.0 (API 26) or later
- Supported ROSE / ROSESELSA earphones

For desktop installation, see [Windows desktop](../windows-desktop/) or [Linux desktop](../linux-desktop/).

The app UI is currently Chinese only, so UI labels on this site include the Chinese text you will see.

## Get the package

- **Releases**: published on [GitHub Releases](https://github.com/DOHEX/OpenRose/releases) with `SHA256SUMS` and build provenance.
- **Development builds**: open a successful run on [GitHub Actions](https://github.com/DOHEX/OpenRose/actions/workflows/ci.yml) and download the `openrose-<version>-dev-<commit>-android` artifact; the `.apk` inside it is the Android development build. Downloading requires GitHub sign-in, and artifacts are kept for 14 days.

To verify files downloaded from a release:

```bash
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify openrose-<version>-android.apk -R DOHEX/OpenRose
```

## Connect the earphones

<Steps>

1. Install the APK.

2. Pair and connect the earphones in the **system Bluetooth settings**. OpenRose does not handle audio pairing.

3. Open OpenRose and grant the requested permissions. On Android 8–11, scanning for new earphones requires location permission and system location services. Control of already-paired earphones is available separately.

4. Paired earphones show up on the My Earphones (我的耳机) page. Once they connect to system audio, OpenRose opens the control connection automatically; add new earphones with **+** in the top right.

</Steps>

## Control connection and audio connection

OpenRose's **control connection** is separate from the **audio connection** the system uses for music and calls:

- The control connection reads state such as battery and mode, and sends settings.
- "Disconnect control connection" (断开控制连接) in the app asks for confirmation, then disconnects only OpenRose; playback is not affected.
- When the earphones connect to system audio, the control connection opens automatically; when audio disconnects (for example, the earbuds go back in the case), the control connection ends with it.
