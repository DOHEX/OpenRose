## 功能

<CardGrid stagger>
	<Card title="耳机控制" icon="setting">
		电量与固件版本、降噪与通透档位、游戏模式、EQ、触控按键、佩戴检测与多点连接。可用项随型号和固件变化。
	</Card>
	<Card title="HyperOS 系统集成" icon="star">
		经 Xposed 模块接入超级岛、焦点通知和融合设备中心；模块控制下由系统蓝牙进程连接耳机，不需要打开 OpenRose。
	</Card>
	<Card title="两种界面风格" icon="laptop">
		Miuix 与 Material 3 Expressive，切换时不断开耳机。支持 Android，以及通过 BlueZ 控制耳机的 Linux 桌面版。
	</Card>
	<Card title="本地与开源" icon="open-book">
		通过本地蓝牙直接与耳机通信，不需要任何账号。以 GPL-3.0-or-later 开源。
	</Card>
</CardGrid>
