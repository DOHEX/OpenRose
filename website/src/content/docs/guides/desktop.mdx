桌面版在 Windows 上通过 WinRT、在 Linux 上通过系统 BlueZ 和 D-Bus 提供 BLE 控制，不含 SPP、OTA 和系统集成。桌面端没有控制方式可选，应用直接持有控制连接。

:::caution[验证状态]
Windows x64 和 Linux x64 的 BLE 控制均已实现，EarFree i5 在桌面端的完整真机验收尚未完成。读数、控制与音频播放的验证情况见[平台支持](../../reference/platforms/)。
:::

## 安装与连接

安装包与 Android 版发布在同一处，见[快速开始](../getting-started/#获取安装包)。

<Tabs>
<TabItem label="Linux">

Linux x64 提供以下格式（正式版见 [GitHub Releases](https://github.com/DOHEX/OpenRose/releases)，开发版在 [CI 运行记录](https://github.com/DOHEX/OpenRose/actions/workflows/ci.yml) 的 `openrose-<版本>-dev-<提交号>-linux-x64` 产物中，下载开发产物需要登录 GitHub）：

| 文件 | 适用 | 安装命令示例 |
| --- | --- | --- |
| `openrose_<版本>_amd64.deb` | Debian、Ubuntu 24.04 及以上及其衍生发行版 | `sudo apt install ./openrose_*.deb` |
| `openrose-<版本>-1.x86_64.rpm` | Fedora 等 RPM 发行版 | `sudo dnf install ./openrose-*.rpm` |
| `openrose-<版本>-1-x86_64.pkg.tar.zst` | Arch Linux 及其衍生发行版 | `sudo pacman -U ./openrose-*.pkg.tar.zst` |
| `openrose-<版本>-x86_64.AppImage` | 其他发行版，免安装 | `chmod +x openrose-*.AppImage && ./openrose-*.AppImage` |

软件要求 **GTK 4.14 及以上**。系统包（`openrose`）会声明对 `bluez`、GTK 4.14+、D-Bus、GStreamer 与 GLib 的依赖，安装后提供 `openrose` 命令及名为 **OpenRose** 的桌面入口。AppImage 不打包系统运行库，需要宿主系统已安装 GTK 4.14+、D-Bus、GStreamer 与 BlueZ 并运行蓝牙服务。

使用前先在系统蓝牙设置里配对并连接耳机。如果扫描时状态页显示「D-Bus 拒绝访问蓝牙」，请检查当前桌面用户访问系统 BlueZ 服务的权限。

## 流转配对

手机启用模块并选择「模块控制」。在电脑侧边栏的「耳机流转」页点「开始流转配对」，显示六位配对码和二维码，配对码下方提示有效时间。再在手机的流转配对入口扫码，或选择这台电脑并输入六位码。若是手机或另一台电脑在开始流转配对，则在电脑的「流转配对新对端」里选择局域网内发现的对端，输入它的六位配对码后点「流转配对」。两端须在可互访的局域网内，主机防火墙需允许手机访问桌面的 TCP 21871 端口。

完成流转配对的对端列在「已流转配对的对端」中。每张卡片显示对端名称、它当前接入的耳机、电量与「在线」或「不在线」状态；点「刷新」可重新读取，对端回到局域网后也会自动重新读取。在线时可用卡片里的「降噪模式」条远程切换降噪模式，切换会等对端耳机确认后才生效，音频继续来自原来的音源设备。点「取消流转配对」即可解除该对端。

对端持有耳机时，卡片上会出现「接到这台电脑」，点击后原音源先让出，耳机的音频连接与控制随之转到本机；托盘面板里的对端卡片也有同样的按钮。若对方正在通话、麦克风被占用、响应超时或联系不上任何对端，界面会按错误或结果提示，且不会自动切回。

## 托盘与后台控制

点击托盘图标打开面板，查看当前耳机的名称、连接状态、电量与降噪模式；连接中可点「取消连接」，未连接时可点重新连接按钮重试。

本机没有连接耳机而已配对的对端正在使用耳机时，托盘图标会变为「远端」状态，提示显示“耳机名 · 音源设备名”和电量，面板内可直接点「接到这台电脑」；有多个对端时按配对顺序取第一个。本机连接耳机时始终以本机为准。

托盘面板与菜单会显示当前系统音频输出；当系统装有已知的声音设置程序（如 `pavucontrol`、GNOME/KDE 声音设置或 Windows 声音设置）时，额外提供「打开声音设置」入口。若电量和降噪尚未恢复，可点「恢复耳机控制」重试，音频连接保持在电脑上。

默认会在支持的耳机上同时显示降噪／通透档位（随当前模式出现）、游戏模式与 EQ 预设。可以在侧边栏「托盘与后台」页的「托盘面板控制项」（或点击面板底部的「控制项设置」）中开关降噪／通透档位，并勾选或调整游戏模式、EQ 预设、空间音频与独立麦克风模式的显示顺序。其他配置项可从面板底部打开 OpenRose。

在 Linux 上，托盘图标通过 D-Bus StatusNotifierItem 实现，状态检测依赖 GLib 的 `gdbus`；GNOME 还需要启用 AppIndicator 扩展（GNOME 与 KDE 上的托盘尚未实机验证）。部分桌面环境左键单击会打开托盘菜单：

- **已开启“托盘与后台 → 后台控制”（默认开启）且托盘可用**：关闭窗口只隐藏界面、保留控制连接；从托盘菜单“退出”才结束。
- **关闭“后台控制”或托盘不可用**：关闭窗口即退出。

## 平铺式合成器的窗口规则

在 Linux 的 niri、Hyprland、Sway 等桌面上，托盘面板是由合成器摆放的普通窗口，窗口标题为 `OpenRose 托盘面板`。可以用窗口规则让它浮动到托盘附近，例如 niri：

```kdl
window-rule {
    match title="^OpenRose 托盘面板$"
    open-floating true
    default-floating-position x=12 y=12 relative-to="top-right"
}
```
