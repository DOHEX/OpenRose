在 HyperOS 上，OpenRose 可以作为 Xposed 模块运行，把耳机接入系统界面：

- 系统超级岛和焦点通知呈现连接提示与耳机状态。
- 融合设备中心显示耳机电量、切换降噪模式；在“设置 → 附加设置入口”切换后，“附加设置”可直接跳转到 OpenRose（默认保持系统页）。
- 模块控制：由系统蓝牙进程连接耳机，不需要打开 OpenRose。
- 耳机流转（实验性）：经融合设备中心，把耳机从一台 HyperOS 音源设备转到另一台。

:::caution[验证状态]
在 EarFree i5 和小米 14 上，已确认“附加设置”能打开 OpenRose。在 HyperOS 4.0.0.27 上还观察到两项行为：焦点通知保留卡片时可隐藏摘要态；模块模式可将连接提示与状态通知合并为一个电量岛。入盒重弹、双机流转和 HyperOS 3 仍待实机验证。
:::

## 前提条件

- HyperOS 3 或 4
- 支持 libxposed API 102 的框架，例如 LSPosed 2.2.0 或更新版本

## 启用模块

<Steps>

1. 按[快速开始](../getting-started/)安装 OpenRose 并连接耳机。

2. 在 Xposed 框架中启用 OpenRose 模块，作用域勾选：
   - `com.android.bluetooth`
   - `com.xiaomi.bluetooth`
   - `com.milink.service`

3. 让模块加载：重启手机；或在 OpenRose 的“状态”页点右上角的“重启作用域”（需要 root 授权）。

4. 回到“状态”页，确认模块已就绪。

</Steps>

## 控制方式

在“设置”页选择控制方式：

| 控制方式 | 谁连接耳机 | 说明 |
| --- | --- | --- |
| 普通控制（默认） | OpenRose 应用 | 不需要模块；暂停模块提供的系统集成增强 |
| 模块控制 | 系统蓝牙进程 | 开机解锁后即可使用，不需要打开 OpenRose |

选择只表示意图：模块是否就绪、控制连接是否已建立，在“状态”页分别显示。

从模块切回普通控制时，OpenRose 会保存“普通控制”。若状态页显示正在等待模块释放，应用会继续重试，取得释放确认后自动接管。切到模块控制时，应用先结束普通控制连接，再保存“模块控制”。

## 常驻电量岛与显示时机

在模块模式下，开启焦点通知和“常驻电量岛”可在状态栏查看电量。清空“显示时机”后，电量仍可见，连接和入盒时均保持安静。若只想在连接或入盒时看一眼，可以关闭“常驻电量岛”，再勾选需要的时机。

## 焦点通知点击目标

在“设置”页选择点按耳机状态通知卡片时打开的位置：OpenRose 耳机主页（默认）、系统耳机详情页、RoseLink 或快捷面板。快捷面板是 OpenRose 的底部浮层，不进主界面即可切换降噪模式、EQ 预设与游戏模式；控制中心的 OpenRose 磁贴打开的也是它。

没有安装 RoseLink，或者系统没有耳机详情页时，对应选项不可选，并说明原因。选好的目标之后变得打不开（例如卸载了 RoseLink），点按通知会打开 OpenRose 耳机主页，并在顶部说明原因。

## 耳机流转（实验性）

HyperOS 音源设备之间可以经融合设备中心流转耳机：耳机改由另一台音源设备播放，OpenRose 的控制连接随之转过去。

- 两台音源设备都需要启用 OpenRose 模块，并都选择模块控制；普通控制下不提供。
- 耳机流转不同于多点连接：多点连接是耳机同时连着两台音源设备。
- 该功能尚未完成实机验证。

## 已知限制

- **降噪模式映射**：系统只有“关闭 / 降噪 / 通透”三种模式。耳机处于抗风噪时，融合设备中心显示为“关闭”，实际模式不变。在“设置”页开启“关闭降噪使用抗风噪”后，点“关闭”会写入抗风噪而不是标准模式。
- **电量显示**：耳机电量已知但充电状态未知时，融合设备中心不显示该电量；充电盒电量也不显示。

反馈系统集成问题时，请附上 Xposed 框架版本，以及“状态”页进入诊断后显示的桥接状态，见[反馈问题](../feedback/)。
