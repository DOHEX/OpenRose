## 要求

- Android 8.0（API 26）及以上
- 已适配的 ROSE / ROSESELSA 耳机

桌面版见 [Linux 桌面版](../linux-desktop/)。

## 获取安装包

- **正式版**：发布在 [GitHub Releases](https://github.com/DOHEX/OpenRose/releases)，附带 `SHA256SUMS` 和构建来源证明。
- **开发版**：在 [GitHub Actions](https://github.com/DOHEX/OpenRose/actions/workflows/ci.yml) 打开一次成功的运行，下载 `packages-linux-x64` 产物，里面的 `OpenRose-android-debug.apk` 就是 Android 开发版。下载需要登录 GitHub，产物保留 14 天。

校验正式版下载的文件：

```bash
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify OpenRose-android.apk -R DOHEX/OpenRose
```

## 连接耳机

<Steps>

1. 安装 APK。

2. 在**系统蓝牙设置**里配对并连接耳机。OpenRose 不负责音频配对。

3. 打开 OpenRose 并授予请求的权限。Android 8–11 会请求定位权限，只在扫描附近的新耳机时需要打开系统定位服务。

4. 已配对的耳机会出现在“我的耳机”页。耳机连上系统音频后，OpenRose 自动建立控制连接；新耳机点右上角的 **+** 添加。

</Steps>

## 控制连接与音频连接

OpenRose 与耳机之间的**控制连接**，和系统用来听歌、通话的**音频连接**是两回事：

- 控制连接用来读取电量、模式等状态并发送设置。
- 应用里的“断开控制连接”只断开 OpenRose 自己，不影响播放。
- 耳机连上系统音频时，控制连接自动建立；耳机断开音频（例如放回充电盒）时，控制连接随之结束。
